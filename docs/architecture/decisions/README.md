# 架构决策记录（ADR）

本目录记录 MoGrab 的架构决策。每个 ADR 描述**一个**决策的背景、选项、结论与后果。

## 为什么需要 ADR

MoGrab 的规划书在多处「给出选项但未做选择」。这些悬而未决的问题会在编码时被
临时决定，而临时决定一旦落地就形成了事实上的契约。ADR 把这些决定显式化，
使得：

- 后来者能理解「为什么是这样」而非仅知道「是这样」
- 推翻某个决定时需要先更新 ADR 并说明理由，避免无声回退

## 状态约定

| 状态 | 含义 |
|------|------|
| `提议` | 正在讨论 |
| `已接受` | 已生效，实现应遵循 |
| `已废弃` | 被后续 ADR 取代 |
| `已取代` | 明确由某个新 ADR 替代 |
